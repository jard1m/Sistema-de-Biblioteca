# Sistema de Biblioteca

Trabalho da disciplina de Introdução à Programação em Python, curso de Ciência da Computação. Professora Fernanda.

## O que o programa faz

- Cadastro de livros
- Registro de empréstimos e devoluções
- Busca de livros por titulo

## Como usar

Necessário ter Python instalado e atualizado no sistema do computador.
